# Données du projet

Les données nécessaires au fonctionnement du chatbot ne sont pas incluses dans ce dépôt pour des raisons de confidentialité et de volumétrie.

Pour exécuter le projet, il faut disposer du jeu de données préparé contenant les documents, formulaires et transcriptions vidéo à indexer dans Vespa.
